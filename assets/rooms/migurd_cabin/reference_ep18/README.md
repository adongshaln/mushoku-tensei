# 米格路德族木屋

`bg.png` 以《无职转生》第一季第 18 话的室内镜头为底图。通过 ImageGen 移除了画面中的三名人物，并补绘人物原先遮挡的墙面、木台和石地。成图尺寸为 1672 × 941。陶锅、石圈地炉、梯旁的陶罐和透光的布帘取自同一镜头。

## 在 Godot 中使用

1. 用 `bg.png` 显示房间。所有物件已经画在背景里。
2. 读取 `hotspots.json`。每个热点带同尺寸的透明 PNG 遮罩、归一化轮廓及检视文案。遮罩与背景共用缩放、裁切偏移和左上原点。
3. 将鼠标或触点转换成背景局部坐标，按配置的 `alpha_cutoff` 采样对应遮罩。显示高亮时只绘制遮罩外缘。

帘子延伸至画面左边和上边，高亮时可裁掉贴屏幕边缘的描边。陶锅和地炉分别有独立的命中区域。
