# 魔大陆东北角英雄样板区交接

## 模型与清洗参数

三件原型来自下载目录。Blender 5.2.4 通过 `polish_hero_assets.py -- --input <暂存目录>` 读取按 `输出名_raw.glb` 命名的临时副本。脚本默认也接受 `assets/3d/world_v2/raw_heroes/` 中的同名输入。

| 下载文件 | 成品 | 三角面 | 字节 | 水平最大跨度 | 粗糙度 / 法线强度 |
| --- | --- | ---: | ---: | ---: | --- |
| `sample.glb` | `hero_migurd_village.glb` | 18,794 | 3,076,792 | 0.40 | 0.81 / 0.45 |
| `sample (1).glb` | `hero_rikarisu_town.glb` | 32,321 | 3,807,424 | 0.50 | 0.78 / 0.46 |
| `sample (2).glb` | `kit_demon_cliff_a.glb` | 12,198 | 2,168,340 | 1.00 | 0.85 / 0.50 |

以 `2e-7` 合并重复顶点，按 68° 保留锐边，以面面积和夹角加权重建法线。仅城镇移除了 1 个退化三角面。导出后逐件核对 Y-Up 包围盒，X/Z 居中、底面 Y 为 `-0.02`。三件成品内嵌与原件字节一致的 Albedo，以及用平滑亮度与 Sobel 梯度生成的 1024 × 1024 Non-Color 法线图。GLB 均含 `NORMAL`、`TANGENT` 和 `TEXCOORD_0`，金属度为 `0`。

## 地皮与摆放

- 从裙边低位三角面的原始 Albedo 按面积取样。米格路德砂土约为 `#A07953`，断崖赭岩约为 `#6B2A14`。配色随资产导出至 `hero_ground_palette.json`。
- 地皮着色器在魔大陆样板区内混合两种岩土色，叠加细微岩层和颗粒。覆盖范围为 `Rect2(5.16, -4.49, 2.46, 1.97)`，按相机远近调节细节。场景按城镇和断崖落位生成 `192 × 192` 接地遮罩，供着色器压实接触暗部。
- 17 个候选位通过海拔、城镇范围与陆路净空检查后留下 15 块断崖，分布在盆地边、北岸和南侧山脊。每块按脚下坡度嵌合，并变化旋转、镜像和各轴尺度。清除样板区内干扰城市和断崖的枯木，保留矿晶与低矮碎石。
- 两座城加载英雄模型时隐藏旧城模型。路线以英雄模型包围盒的出口裁切，再留 `0.055` 单位，断崖另为路线留 `0.17` 单位加自身占地半径。村落新模型启用时，将村落雾层透明度系数降至 `0.55`。

## 实机回归与验收图

验收使用本机 Apple M4 的 Godot `4.7.2.stable.official.ed1daf0bf`、Metal 4.0 和 Forward+。在隔离工程及测试存档中验证两城替换、断崖实例数、地皮参数、航线端点净空、陆海寻路、陆行棋子贴地、跟随镜头、船只水位及实际存读档。无头导入和实机日志均为 0 Error / 0 Warning。冻结战斗和并行轨道目录的本次写入为 0。

近景取自游戏的 1920 × 1080 三维视口。预热后按单次绘制循环计时，各连续采样 64 帧，上午平均 36.6 FPS，傍晚平均 34.5 FPS。取景时把诺缇雅停在路肩，便于看清两座城之间的短程金色航线。
